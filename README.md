Pizza-Ordering-System

I created a pizza ordering system using Python language, the feature of this system is to give customers satisfaction and make the ordering more easier and faster. It has four different flavor, a three different sizes, and 3 different toppings. After the order it outputs the order receipt, it outputs the flavor,sizes,topping price, and the overall price of the items you bought.

This project is the requirements for our subject CT5.
